# ✍️ GlyphStudio — Генератор рукописных шрифтов

**GlyphStudio** — веб-приложение, в котором можно нарисовать буквы от руки и сразу скачать готовый шрифт `.ttf`.

Работает на компьютере, планшете и телефоне. Можно установить как приложение (PWA).

**Сайт (GitHub Pages):** `https://Lina1209.github.io/glyph-studio/`

> Description для GitHub:  
> *Генератор рукописных шрифтов .TTF в браузере: кириллица, латиница, живой предпросмотр, PWA для телефона и планшета*

## ✨ Что умеет

- Каллиграфическая кисть с настройкой толщины и заострения
- Сетка символов: кириллица, латиница, цифры и знаки
- Типографские направляющие (базовая линия, прописные, строчные)
- Предпросмотр текста в реальном времени
- Экспорт TrueType-шрифта (`.ttf`) без установки программ
- Автовыравнивание глифов по левому краю
- Автосохранение прогресса в браузере
- Установка как приложение на Android и iPhone (PWA)

## 👤 Для кого

- дизайнерам и иллюстраторам
- авторам шрифтов-новичкам
- тем, кто хочет «свой почерк» в документах и макетах

## 🚀 Как пользоваться

1. Откройте сайт
2. Выберите букву и нарисуйте её
3. Проверьте слово в окне предпросмотра
4. Нажмите **«Скачать .TTF»**

## 📱 Установка на телефон

После публикации на GitHub Pages:

- **Android (Chrome):** меню → «Установить приложение» / «Добавить на главный экран»
- **iPhone (Safari):** Поделиться → «На экран „Домой“»

## 🛠 Технологии

- HTML5 / Tailwind CSS / Vanilla JavaScript
- [perfect-freehand](https://github.com/steveruizok/perfect-freehand) — контуры кисти
- [opentype.js](https://github.com/opentypejs/opentype.js) — сборка `.ttf`

Сборка и сервер не нужны — достаточно открыть `index.html` или выложить на GitHub Pages.
