# ✍️ GlyphStudio — студия рукописных шрифтов

**GlyphStudio** — браузерная мастерская для создания собственных шрифтов. Рисуйте буквы и знаки вручную, редактируйте векторные контуры, проверяйте текст в живом предпросмотре и экспортируйте результат в TrueType (.ttf).

**Сайт:** https://Lina1209.github.io/glyph-studio/

Приложение работает на компьютере, планшете и телефоне. На поддерживаемых устройствах его можно установить на главный экран как PWA.

## Возможности

### Векторный редактор
- Каллиграфическая кисть с регулировкой толщины и заострения.
- Перо Безье: узлы, кривые и управляющие ручки.
- Выделение, перемещение, масштабирование, поворот и отражение объектов.
- Добавление, удаление и сглаживание узлов.
- Геометрический ластик с точным вычитанием областей, сохранением отверстий и разделением фигуры на отдельные части; отмена и повтор действий.
- Направляющие, масштабирование и перемещение холста.
- Импорт символов из шрифтов TTF/OTF, PNG/JPG и SVG.
- Вставка изображения из буфера обмена и перетаскивание файла на холст.

### Библиотека глифов
- Кириллица: заглавные и строчные буквы, включая Ё/ё.
- Латиница: заглавные и строчные буквы.
- Цифры и основные знаки препинания.
- Отдельное редактирование каждого символа.
- Автосохранение проекта в локальном хранилище браузера.
- Резервное копирование всего проекта в JSON и восстановление из файла с проверкой структуры и подтверждением замены.

### Бланк рукописного ввода
1. Откройте блок «Рукописный бланк».
2. Распечатайте все страницы или скачайте нужную страницу в SVG.
3. Впишите символы в соответствующие ячейки тёмной ручкой.
4. Сфотографируйте лист целиком, не обрезая чёрные угловые метки.
5. Загрузите фото PNG, JPG или WebP и выберите страницу.
6. Нажмите «Распознать и добавить в библиотеку».
7. Проверьте полученные контуры и при необходимости отредактируйте их.

Если буква уже нарисована, по умолчанию она не перезаписывается. Для замены включите соответствующий флажок перед распознаванием. Сканирование выполняется в браузере; загруженное изображение не отправляется на сервер приложения.

Распознавание использует угловые метки для выравнивания листа и трассировку контрастных штрихов. Качество зависит от освещения, контраста и перспективы снимка — после импорта обязательно проверьте символы.

### Предпросмотр и экспорт
- Живой предпросмотр текста с использованием нарисованных глифов.
- Ненарисованные символы показываются системным шрифтом.
- Экспорт готового шрифта TrueType (.ttf) через opentype.js.

## Установка на телефон

После открытия сайта:
- **Android / Chrome:** меню браузера → «Установить приложение» или «Добавить на главный экран».
- **iPhone / Safari:** «Поделиться» → «На экран „Домой“».

Service Worker кэширует приложение и его основные модули для повторного открытия без сети после первого успешного онлайн-запуска. Для загрузки внешних библиотек и первого запуска требуется интернет.

## Технологии

- HTML5, CSS, Tailwind CSS и Vanilla JavaScript.
- perfect-freehand — каллиграфическая кисть.
- opentype.js — создание TTF.
- Clipper 6 — булевы операции над контурами для геометрического ластика (лицензия Boost Software License 1.0; уведомление — `lib/CLIPPER-LICENSE.txt`).
- JavaScript-модули для генерации бланка и распознавания рукописных контуров.

Сборка и сервер не требуются: приложение публикуется как статический сайт через GitHub Pages.

## Локальная разработка

Основные файлы:
- index.html — интерфейс и основной редактор.
- lib/project.js — группы символов.
- lib/worksheet.js — генерация бланков и распознавание сканов.
- lib/clipper.js — геометрические операции ластика; `lib/CLIPPER-LICENSE.txt` — лицензия сторонней библиотеки.
- sw.js — кэширование и офлайн-режим.
- manifest.json — настройки устанавливаемого приложения.

Для проверки Service Worker и установки PWA используйте HTTPS или локальный сервер. Открытие файла напрямую через file:// не поддерживает все возможности PWA.
